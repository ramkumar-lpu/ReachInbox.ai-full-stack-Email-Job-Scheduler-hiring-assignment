# Frontend (Dashboard Placeholder)

This directory is reserved for **Phase 4** of the ReachInbox assignment.

In Phase 4, a modern dashboard (e.g. Next.js / React with Tailwind CSS) will be created here to:
- Connect to the backend REST API.
- Allow users to schedule new email jobs (recipient, delay, body, subject).
- Display real-time list of pending, running, completed, and failed jobs.
- Provide a search bar powered by Elasticsearch to filter emails and job statuses.
